# How Artificial Intelligence Works

## About This Project
This project is an educational infographic designed to explain the basic working process of Artificial Intelligence in a simple and visual way.

## Key Stages

1. **Data Collection** – Gathering information from different sources.
2. **Data Processing** – Organizing and preparing the collected data.
3. **Machine Learning** – Learning patterns from the data.
4. **Prediction & Decision** – Using learned patterns to make predictions or decisions.
5. **Output Generation** – Producing the final result.

## Project Purpose
To make the concept of Artificial Intelligence easy to understand through a clear and engaging infographic.
